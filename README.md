##  Overview

Todo App is a task management application built with Flutter that helps users organize their daily activities efficiently.

The application uses **Sqflite** for local data persistence and **Cubit** for state management, providing a smooth and responsive user experience while demonstrating CRUD operations and local database management.

---

##  Features

*  Create New Tasks
* Update Existing Tasks
*  Mark Tasks as Completed
*  Archive Tasks
*  Delete Tasks
*  Local Data Storage using Sqflite
* State Management with Cubit
*  Responsive and Clean UI
